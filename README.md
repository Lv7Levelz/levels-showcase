# Levels Local Showcase

Flagship static website for Levels Local.

## Local preview
Open `index.html` in a browser, or serve the folder with any simple static server.

## GitHub Pages
This repository is designed to deploy directly from the repository root using GitHub Pages.

## Before production launch
- Replace `hello@example.com` with the confirmed Levels Local business email.
- Replace the temporary CSS brand mark with the approved final logo if desired.
- Update canonical / sitemap URLs if a custom domain is connected.
- Add approved real client work, testimonials and case studies only when available.
